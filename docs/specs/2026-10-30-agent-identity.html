RECOMMENDATION

A안부터 작게 적용합니다.

현재 크기를 유지하면서 모든 줄의 두 번째 행에 Claude / Codex 이름 배지를 붙입니다. 답장 헤더에도 같은 배지를 사용해, 어떤 에이전트에게 답하는지 이어서 보여 줍니다.

  1. 주황·파랑·초록 상태 점의 의미를 유지합니다. Codex 배지는 중립색, Claude 배지는 차분한 갈색을 사용하고 이름도 항상 읽을 수 있게 둡니다.
  2. 대기 → 진행 → 완료 순서와 접힌 알약의 상태별 합계를 유지합니다. 에이전트별로 그룹을 쪼개지 않습니다.
  3. 필터는 후속 선택 사항입니다. 켜서 비교할 수 있으며, 적용 시 합계도 필터 범위임을 명시합니다.
이번 시안의 범위는 에이전트 종류 구분입니다. 자동화 여부는 별개의 정보입니다. 현재 직접 실행 / 자동화 분류는 구현돼 있지 않으므로, 이 시안에도 자동화 배지를 붙이지 않았습니다. 터미널 아이콘은 계속 실행 위치를 뜻합니다. CL·CX는 이 문서의 비교용 약어이며 공식 로고가 아닙니다.
