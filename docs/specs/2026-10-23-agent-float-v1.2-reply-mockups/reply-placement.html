B. 옆에 답장 카드

목록은 그대로 두고, 패널 옆에 유리 카드가 하나 더 뜹니다.

  • 목록과 질문을 같이 봄, 다른 대기 줄로 바로 바꿔 탈 수 있음
  • 화면을 가장 넓게 차지함. 패널이 화면 가장자리에 있으면 반대쪽으로 뜸

C. 패널이 답장 화면으로 바뀜

패널 내용이 그 세션 하나로 바뀌고, "‹ 목록"으로 돌아갑니다.

  • 질문에 집중, 패널 크기가 크게 변하지 않음
  • 답하는 동안 다른 세션 목록은 안 보임 (맨 위 요약 줄만 보임)

세 안 모두 공통: 대기 줄을 누르면 지금처럼 바로 이동하지 않고 답장 화면이 열리며, 이동은 "터미널로 이동"으로 합니다. 답장 화면이 열려 있는 동안에는 마우스가 벗어나도 패널이 접히지 않습니다.
